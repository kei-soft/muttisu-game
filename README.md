## 소개

레트로 아케이드 감성의 HTML 게임 모음입니다.
슈팅, 생존, 리듬, 채굴, 퍼즐까지 장르별로 11개의 게임이 들어 있고,
런처에서 원하는 게임을 골라 바로 실행할 수 있습니다.

- 사이드바에서 게임 선택 · 이름 검색
- 새로고침 / 새 창 / 전체화면 지원
